# Visual Question Answering (VQA) на основе CLIP, BERT и Transformer

Система визуального ответа на вопросы (**Visual Question Answering, VQA**), объединяющая визуальные признаки из **CLIP**, текстовые представления из **BERT** и собственную мультимодальную архитектуру на базе **Transformer Encoder**.

Модель обучалась и тестировалась на датасете **VQA v2.0** с использованием изображений **MS COCO 2014 Validation**.

## Архитектура модели

```text
Изображение
     │
     ▼
 CLIP ViT-B/32
     │
     ▼
Патч-эмбеддинги (50 × 512)
     │

     │
     ▼

Вопрос
     │
     ▼
 BERT Base
     │
     ▼
Текстовые токены (25 × 768)

[FUSION TOKEN]
       +

       +
Визуальные токены

            │
            ▼
   Transformer Encoder
          (4 слоя)

            │
            ▼
      Fusion Token

            │
            ▼
 Классификатор ответов
     (5000 классов)
```

## Используемый датасет

### VQA v2.0

Для обучения использовались:

* `v2_OpenEnded_mscoco_val2014_questions.json`
* `v2_mscoco_val2014_annotations.json`
* изображения из набора **MS COCO 2014 Validation**

Каждый объект датасета содержит:

```json
{
  "image_path": "...",
  "question": "...",
  "answer": "...",
  "all_answers": [...]
}
```

В качестве пространства ответов используются **5000 наиболее частотных ответов**.

## Подготовка данных

### 1. Объединение вопросов и ответов

```bash
python concatenate.py
```

Результат:

```text
vqa_val2014_preprocessed.json
```

Скрипт объединяет вопросы, ответы и пути к изображениям в единый JSON-файл.

---

### 2. Компиляция метаданных

```bash
python convert_meta.py
```

Что выполняется:

* токенизация вопросов через BERT Tokenizer;
* построение словаря ответов;
* генерация soft-target меток по всем аннотациям VQA.

Результат:

```text
ans2idx.json
embeddings/val_vqa_compiled_metadata.pt
```

---

### 3. Извлечение визуальных эмбеддингов

```bash
python extract_embeddings.py
```

Для каждого изображения извлекаются патчевые признаки CLIP.

Результат:

```text
embeddings/val_vqa_patches_dict.pt
```

## Обучение модели

Запуск:

```bash
python model.py
```

Параметры обучения:

| Параметр                     | Значение         |
| ---------------------------- | ---------------- |
| Размер батча                 | 612              |
| Эпохи                        | 15               |
| Оптимизатор                  | AdamW            |
| Планировщик LR               | Cosine Annealing |
| Mixed Precision              | AMP              |
| Gradient Clipping            | 1.0              |
| Размер скрытого пространства | 768              |
| Количество голов внимания    | 12               |
| Количество Transformer-слоёв | 4                |

## Запуск инференса

```bash
python main.py
```

После запуска открывается окно веб-камеры.

### Управление

| Клавиша | Действие                |
| ------- | ----------------------- |
| R       | Задать голосовой вопрос |
| Q       | Выход                   |
| ESC     | Выход                   |

---

## Конвейер работы

1. Захват изображения с веб-камеры.
2. Запись голосового вопроса.
3. Распознавание речи через Whisper.
4. Извлечение визуальных признаков CLIP.
5. Кодирование вопроса через BERT.
6. Мультимодальное объединение признаков.
7. Предсказание ответа моделью.
8. Вывод результата на экран.
